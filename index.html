About

I am a senior software engineer at Netelsan in Ankara, working on backend and platform engineering for IP intercom, burglar alarm and smart-home products: WebRTC service infrastructure on AWS, observability with Prometheus and Grafana, and the automated release pipeline that feeds the production line.

I enjoy building things from scratch — network servers, parsers, CLI tools — and I care about the low-level details: memory management, concurrency, I/O protocols and performance tuning.

Before that, I was the sole engineer on a company-wide ERP for a Saudi contracting firm (Java, Spring Boot, React, Flutter), built mobile and fleet-tracking apps at Bitcraft, and started my career as a system and network engineer in the Turkish Naval Forces. I hold a BSc in Computer Engineering from Karadeniz Technical University.
